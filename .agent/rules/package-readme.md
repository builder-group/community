# Package READMEs

Use this guide for reusable package and tool documentation, alongside [writing.md](writing.md).

- Explain what the package enables and show a compact, practical example early
- Follow with installation and common usage
- Document public behavior and non-obvious constraints
- Add API sections, comparisons, migration notes, and FAQ only where useful

Use the [feature-state README](https://github.com/builder-group/community/blob/develop/packages/feature-state/README.md) or [tuple-result README](https://github.com/builder-group/community/blob/develop/packages/tuple-result/README.md) as a structure and style reference, adapting sections to the package.
