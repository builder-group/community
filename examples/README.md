# Examples

Small projects that show the packages in realistic, minimal setups.

## Frontend

- `feature-fetch/vanilla/basic`: vanilla TypeScript example for REST, OpenAPI, and GraphQL fetch clients
- `feature-form/react/basic`: React form example with typed fields and validation
- `feature-state/react/basic`: React state example with derived values, undo, and persisted settings

## Backend

- `openapi-ts-router/express/petstore`: Express 5 Petstore API example with generated OpenAPI types
- `openapi-ts-router/hono/petstore`: Hono Petstore API example with generated OpenAPI types
